# tokentamer

Audits a project's Claude Code session transcripts (not its code) for evidence-backed ways it could have used fewer tokens. Triggers on requests like "review our sessions for token waste" or "check if we're using the right model/MCPs/skills". Run `/tokentamer --help` for usage.
